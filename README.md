# Project Management App

A modern and intuitive project management application designed to help teams organize work, track progress, and collaborate more effectively. Built with Next.js, TypeScript, Prisma, Clerk, and React DnD, this project provides a streamlined experience for managing tasks through a visual Kanban-style workflow.

## Overview

This application is crafted to simplify project execution by bringing key project information into a single, user-friendly interface. It allows users to manage workspaces, projects, and tasks efficiently while keeping an eye on deadlines, labels, and recent activity.

## Key Features

- Kanban-style boards for task management
- Drag-and-drop task movement between columns
- Task organization with labels, due dates, and descriptions
- Activity tracking for project updates and team actions
- Clean and responsive interface for product and development teams

## Tech Stack

- Next.js
- React
- TypeScript
- Prisma ORM
- Clerk Authentication
- React DnD

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the application in your browser.

## Purpose

This project serves as a practical example of building a polished project management dashboard with modern web technologies, focusing on usability, structure, and a professional user experience.
